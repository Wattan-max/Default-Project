# Default Project

Starter repository for the `Default Project` workspace.

## Getting started

Clone this repository:

```bash
git clone https://github.com/Wattan-max/Default-Project.git
cd Default-Project
```

Make your changes, then commit and push:

```bash
git add .
git commit -m "Describe your change"
git push
```
